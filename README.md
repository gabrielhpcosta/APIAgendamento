# API Agendamento

API REST desenvolvida em Java com Spring Boot para gerenciamento de agendamentos.

## Tecnologias
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- H2 Database
- Lombok

## Funcionalidades
- Criar agendamento
- Buscar agendamentos por data
- Alterar agendamento
- Deletar agendamento
